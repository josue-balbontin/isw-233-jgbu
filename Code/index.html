Sobre Mí

Soy un ingeniero en software con experiencia en desarrollo web y móvil. Me apasiona crear soluciones innovadoras y eficientes para resolver problemas complejos. Mi objetivo es seguir creciendo profesionalmente y contribuir al éxito de proyectos desafiantes.

Proyectos Destacados

Proyecto 1: Aplicación de Gestión de Tareas

Desarrollé una aplicación web para gestionar tareas y proyectos, utilizando React para el frontend y Node.js para el backend. La aplicación permite a los usuarios crear, editar y eliminar tareas, así como asignarlas a diferentes proyectos.

Proyecto 2: Aplicación Móvil de Fitness

Creé una aplicación móvil para seguimiento de actividades físicas, utilizando Flutter. La aplicación permite a los usuarios registrar sus entrenamientos, establecer metas y monitorear su progreso a lo largo del tiempo.

Proyecto 3: Aplicación de Gestión de Inventario

Desarrollé una aplicación web para gestionar inventarios, utilizando React para el frontend y Node.js para el backend. La aplicación permite a los usuarios registrar productos, actualizar cantidades y generar reportes de inventario.
